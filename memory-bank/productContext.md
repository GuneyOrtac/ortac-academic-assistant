# Ürün Bağlamı

## Neden Bu Proje?
Mevcut akademik araçlar (ChatGPT Plus, Mendeley Premium vb.) pahalı ve bulut bağımlı. Bu proje, gizlilik odaklı, yerel çalışan ve çok düşük maliyetli (450 TL bakiye ile milyonlarca token) bir alternatif sunar.

## Temel Değer Önerileri
1. **Gizlilik:** PDF'ler ve vektör DB kullanıcının bilgisayarında kalır
2. **Düşük Maliyet:** Gemini Flash modelleri ile 1M token ~1 USD
3. **Sıfır Halüsinasyon:** OpenDraft ile kesin atıf kontrolü
4. **Taşınabilirlik:** Docker + .akpack ile kolay yedekleme
5. **Otonom Araştırma:** OpenAlex + PASA atıf ağı ile kaynak bulma

## Rakiplerden Farkı
- Sadece chat değil: PDF tasnif, RAG, taslak üretimi, Zotero entegrasyonu
- Agentic Routing: İşleme göre 3 farklı API modeli
- Off-Peak otomatik planlama ile %50 tasarruf
